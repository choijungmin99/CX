# 지상 점프와 2층 스카이 코스

별도의 점프 키 없이 차량의 속도와 경사로를 이용해 도약합니다. 중력이나 차량 속도를 강제로 바꾸지 않고 Chaos 차량 물리로 체공하고 착지합니다.

[경기장 전체 모습](../Deliverables/SkyCourse_Overview.png)

| 구간 | 표지 | 구성 |
|---|---|---|
| 지상 점프 | AIR JUMP | 점차 높아지는 램프, 열린 공중 구간, 넓은 내리막 착지 구간 |
| 2층 진입 | 2F UP | 시작과 끝의 경사를 완만하게 연결한 진입로, 약 14m 높이의 고가 도로 |
| 2층 점프 | AIR JUMP | 약 23m 높이의 도약대에서 40m 간격을 넘어 2층 도로에 착지 |
| 평탄한 우회 | BYPASS | 점프 구간을 피해서 같은 높이로 건너가는 고가 우회로 |
| 지상 복귀 | DOWN | 완만한 하강 램프로 1층에 복귀 |

점프는 **80–110km/h** 정도로 진입하는 것을 권장합니다. `SLOW CORNER` 표지에서는 감속해 방향을 바꾸세요. 민트색 화살표가 진행 방향을 안내하며, 새 코스에도 코인과 속도 아이템을 배치했습니다.

## 실제 주행 확인

`VerifyCourse.cmd`는 별도 호스트와 클라이언트를 실행해 실제 클라이언트의 가속 입력으로 주행합니다. 차량을 공중으로 강제 이동시키지 않습니다.

[CourseReport.json](CourseReport.json)의 **9개 검증 항목이 모두 통과**했습니다.

| 측정 | 지상 점프 | 2층 점프 |
|---|---|---|
| 체공 시간 | 약 3.4초 | 약 3.2초 |
| 최고 높이 | 약 23.9m | 약 32.7m |
| 착지 | 내리막·지상 도로 | 2층 도로 |

높이는 경기장 원점 기준이며, 체공 시간은 실제 진입 속도와 획득한 속도 보너스에 따라 달라집니다. 1층과 2층의 충돌, 2층 진입로 등판, 도약과 착지를 각각 확인했습니다.

실제 클라이언트 캡처: [지상 체공](../Deliverables/SkyCourse_GroundJump.png), [2층 체공](../Deliverables/SkyCourse_UpperJump.png), [2층 착지](../Deliverables/SkyCourse_UpperLanding.png).
