# 제출본 최종 확인

확인일: **2026-10-28**. 대상은 UE **5.5.4**의 `CX` 프로젝트입니다.

## 빌드와 실제 네트워크 검증

- `Scripts/cx.py test`로 에디터 모듈을 빌드한 후 호스트와 게스트를 별도 프로세스로 실행했습니다.
- [NetworkReport.json](NetworkReport.json)의 **40개 항목이 모두 통과**했습니다.
- 실제 게스트 주행, 채팅 전달, 원화·추가 속도 소유자 전용 복제, 부족한 잔액 보호, 정확한 5원 탈취와 연사 제한을 확인했습니다.
- 서버 라인트레이스로 `Phys_Wheel_BL`을 명중시켜 바퀴 페널티와 회복을 확인했습니다.
- 코인·속도 버프 획득, 2초 뒤 같은 종류 재생성, 지뢰 Owner, 가속 고장과 2초 회복을 확인했습니다.
- 대기·종료 상태의 요청 차단, 단독·공동 우승, 재경기 초기화를 확인했습니다.
- 재경기에 두 차량이 서로 다른 출발 위치에 생성되고, 양쪽 모두 Chaos 물리 시뮬레이션을 유지하는지 추가 확인했습니다.
- 검증용 차량 고정과 입력 주입은 `-CXNetTest` 실행에서만 사용됩니다. 일반 플레이는 Vehicle 템플릿의 실제 Chaos 물리 주행을 사용합니다.

## 2인 실행 확인

- 기존 에디터의 개인 실행 설정이 `1명 / Standalone`으로 저장되어 실제 한 명만 실행되는 것을 로그에서 확인했습니다. 이 PC의 과제 프로젝트 설정을 `2명 / Listen Server`로 수정했습니다.
- 화면에 접속 역할과 인원(`리슨 호스트 / 클라이언트`, `접속 2/2명`)을 표시합니다. 오프라인이나 상대 미접속 상황도 별도로 안내합니다.
- `PlayMultiplayer.cmd`는 일반 플레이용 호스트와 게스트를 960×600 크기의 두 창으로 실행합니다. 자동 검증용 차량 고정은 사용하지 않습니다.
- 같은 PC에서는 각 창을 클릭해 W/A/S/D로 운전합니다. 별도 PC의 플레이어는 호스트 IP로 접속해 자신의 차량을 조작합니다.
- 재경기 시 이전 차량을 모두 정리한 다음 차량 위치를 함께 검사하여 같은 출발 지점의 중복 선택을 방지합니다.
- 에디터의 백그라운드 CPU 제한은 `EditorSettings` 설정 계층을 사용하는 `Config/DefaultEditorSettings.ini`에서 해제합니다. `EditorPerProjectUserSettings`에 넣으면 이 성능 설정에는 적용되지 않습니다.

## 차량 피격 효과

- 피격 효과는 맞은 차량의 메시와 Bone에 부착합니다. 서버가 피격 부위의 상대 위치와 표면 방향을 전달하므로 클라이언트에서도 움직이는 차량의 같은 부위에 재생됩니다.
- 피격 전용 파티클 사본을 로컬 공간으로 설정하여 이미 방출된 파티클도 차량 이동과 회전을 따라갑니다. 코인 등에 사용하는 공용 원본 애셋은 수정하지 않습니다.
- `HitEffectDuration`의 기본값은 0.8초입니다. 이후 파티클 발생을 멈추고 남은 파티클이 소멸하면 자동 정리합니다. 피격 사운드도 해당 부위를 따라갑니다.
- 변경 후 UE 5.5 에디터 모듈 빌드와 기존 실제 2프로세스 네트워크 검증 40개를 다시 통과했습니다.

## 코인 획득 효과음

- 코인은 전용 SoundWave `/Game/Mining/Audio/S_CoinPickup`을 사용합니다. 원본은 `SourceAssets/Audio/CoinPickup.wav`에 있습니다.
- 0.38초 길이의 밝은 두 음으로 구성했고, 반복 재생과 기존의 높은 피치 보정 없이 원래 피치 1.0으로 재생합니다.
- 짧은 획득음의 재생 지연을 줄이도록 PCM과 Force Inline으로 가져왔습니다. 원본 생성과 애셋 가져오기는 각각 `Scripts/create_coin_sound.py`, `Scripts/import_coin_sound.py`로 재현할 수 있습니다.
- 애셋 가져오기는 오류·경고 없이 완료했고, 변경 후 빌드와 실제 2프로세스 네트워크 검증 40개를 통과했습니다.

## 지상 점프와 2층 코스

- 지상 체공용 램프와 넓은 착지 구간, 14m 높이의 고가 도로, 진입·하강 램프, 고가 점프와 평탄한 우회로를 추가했습니다.
- 새 코스에 코인·속도 아이템 스포너 20개를 배치했습니다. 기존 출발 지점과 지상 아이템은 보존합니다.
- 실제 바퀴 접촉으로 접지를 판정하여 지상·체공 중 회전 감쇠를 구분합니다.
- [CourseReport.json](CourseReport.json)의 실제 클라이언트 물리 주행 검증 9개가 모두 통과했습니다. 지상 약 3.4초, 2층 약 3.2초의 체공과 2층 착지를 확인했습니다.
- 코스 위치와 실제 화면은 [SkyCourse.md](SkyCourse.md)에 있습니다.

## 제출 파일과 실행

- `CX.uproject`, `Source`, `Config`, `Content`, `Scripts`, `Docs`, `Deliverables`를 하나의 저장소에 포함합니다.
- `Binaries`, `Intermediate`, `Saved`, `DerivedDataCache`, `.Tools`는 Git에서 제외합니다.
- `PlayMultiplayer.cmd`: 일반 2인 플레이 실행.
- `VerifyMultiplayer.cmd`: 빌드와 실제 네트워크 검증 재실행.
- `Build.cmd`: 에디터 모듈 빌드.
- 프로젝트 구조와 조작법은 [README](../README.md), 항목별 구현 위치는 [Requirements](Requirements.md)에 있습니다.

GitHub 원격 저장소 주소는 아직 지정되지 않았습니다. 로컬 저장소의 커밋을 원격에 올린 뒤 해당 링크와 MP4를 제출하면 됩니다. LMS 제출은 수행하지 않았습니다.
